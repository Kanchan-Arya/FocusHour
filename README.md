# ☕ Focus Hour

**Your little corner of focus.**

Focus Hour is a minimal, calming study productivity website designed to help students stay focused, organize their daily tasks, and track their progress in a peaceful digital space.

## ✨ Features

- ⏱️ **Focus Timer** — a 59-minute timer to support focused study sessions.
- 📝 **Task Manager** — add and delete tasks as you plan your day.
- 📊 **Progress Tracker** — keep track of your task completion.
- 💾 **Local Storage** — tasks can be saved in your browser between visits.
- 🤎 **Minimal Design** — a warm cream-and-brown aesthetic for a distraction-free experience.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
